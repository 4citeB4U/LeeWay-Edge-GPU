# Machine Consciousness ↔ Edge GPU boundary

Canonical map: [Machine Consciousness cross-repository integration v1](https://github.com/4citeB4U/Machine-Consciousness/blob/main/docs/architecture/leeway-cross-repository-integration-v1.md).

Edge GPU provides authorized host-local compute and model/GPU adapters. Machine Consciousness and Formula govern eligibility; Device Bridge supplies host grants and capability vectors; Runtime Fabric routes bounded work; Veritas checks measured results; Receipt Authority and Continuum preserve evidence.

No source file, GPU catalog, VRAM record, or WebGPU/Metal/Vulkan configuration proves physical execution. GPU work must carry device identity, adapter version, pre-state, allocation/thermal measurements, post-state, and recovery evidence. Quantization, pruning, distillation, shader compilation, and performance claims require baseline/post-transform evaluation and independent verification.
