## Mission and owner decisions (G16)

The intended product is a **genuine virtual graphics and compute adapter** whose Windows-visible display name is **LeeWay Edge GPU**. Native Windows GPU recognition, real command submission, readback, API exposure, and truthful diagnostics are mandatory; a friendly name, PnP stub, WebGPU compute service, WARP, Vulkan ICD alone, or indirect-display-only driver does **not** satisfy this mission. Preserve Intel and NVIDIA physical graphics hardware and drivers; do not replace, disable, impersonate or mislabel either. Show physical hardware and LeeWay compute capability separately in the LeeWay Diagnostics Matrix, with measured telemetry only. Parallel cross-platform design, Windows implementation first; Apple must use supported native APIs and accurately disclose OS registration limitations.

**Authorized:** official Microsoft Visual Studio C++ Build Tools, Windows SDK, Windows Driver Kit installation; non-disruptive local code, compilation, tests, evidence; isolated VM-first driver testing. **Not authorized without separate explicit approval:** host driver installation/activation, reboot, graphics-driver replacement, security/test-signing changes, or GitHub commit/push. Keep all changes local. Do not reset or overwrite dirty working trees. A VM test must be completed before even requesting host installation approval.

## Canonical architecture and reuse-before-build

Use existing canonical Formula, Runtime Fabric, LDWMD, Continuum, Device Bridge, and Veritas. Do not fork or replace their authorities. Formula governs decisions; Runtime Fabric binds execution authority; LDWMD governs memory residency; Continuum owns retained state; Device Bridge owns device discovery and permissions; Veritas independently verifies evidence. The GPU backend is a subordinate executor, not a new sovereign authority. Classification before implementation: ALREADY BUILT / PARTIALLY BUILT / MISSING GLUE / TRULY MISSING, with actual paths and commits. No silent CPU inference fallback; no existing NVIDIA/Intel GPU inference may be labeled LeeWay-exclusive. Preserve non-LLM operation.
