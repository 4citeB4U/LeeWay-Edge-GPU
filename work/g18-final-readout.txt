G18 discovery is complete, and the first native execution prototype runs real D3D12 compute. It dispatched 262,144 values on the NVIDIA RTX 5060 and Intel Graphics adapters; both readbacks matched the CPU reference with zero mismatches. I recorded the build and evidence in the LeeWay Edge GPU repository and updated the contributor ledger; J-5 and J-7 have exchanged acknowledgments.

This proves a real workload ran on the existing physical GPUs. The prototype is not yet authorized through Runtime Fabric and does not create a separate LeeWay Windows GPU. Windows still does not enumerate a LeeWay adapter, and the WDK driver build components are missing. I also found no applicable GPU-specific Veritas verifier in the inspected canonical sources, so shared S2 remains blocked pending that binding and runtime integration. No driver was installed and no security settings were changed.
